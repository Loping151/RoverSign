# RoverSign

鸣潮、战双、库街区签到插件，依赖 [XutheringWavesUID](https://github.com/Loping151/XutheringWavesUID) 及其数据库。

## 安装

```shell
cd gsuid_core/gsuid_core/plugins
git clone --depth=1 https://github.com/Loping151/RoverSign
```

## 配置

网页控制台 → 插件配置 → RoverSign。签到开关默认全部关闭，按需打开：

| 我想要 | 怎么设置 |
| --- | --- |
| 用户发送「签到」自己签 | 打开 `手动签到：鸣潮` `手动签到：战双` `手动签到：库街区任务` |
| 用户发送「开启自动签到」后每天自动签 | 打开 `自动签到：游戏` `自动签到：库街区任务` |
| 无需用户开启，给所有人自动签 | 打开 `自动签到：全部账号` |
| 自动签到不签战双 | 在 `自动签到的游戏` 中取消「战双」 |
| 签到后通知用户 | 打开 `签到私聊报告` `签到群组报告` |
| 主人每天收到汇总 | 发送「订阅签到结果」 |

修改 `自动签到时间`、`反复签到` 后需重启。

## 指令

默认前缀 `ww`。

| 指令 | 说明 |
| --- | --- |
| 签到 | 立即签到 |
| 开启 / 关闭自动签到 | 鸣潮及已绑定的战双 |
| 开启 / 关闭战双自动签到 | 仅战双 |
| 全部签到 | 主人，立即执行一次自动签到 |
| 订阅 / 取消订阅签到结果 | 主人 |
| 签到帮助 | |
